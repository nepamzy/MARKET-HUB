# MARKET HUB — UI SCREEN BLUEPRINTS

These are design targets. They do not authorize future-phase implementation.

## Login
Centered clean form, calm neutral background, logo, email, password, forgot password, sign in, create account. Optional desktop side value panel. Single column mobile.

## Registration
Progressive flow:
1. account information
2. account category
3. business type only if applicable

Avoid unnecessary first-step data collection.

## Organization Setup
Desktop: form + explanatory side panel.
Mobile: single column.
Clearly explain that organization is the business identity.

## Application Shell
Desktop: left sidebar + top utility bar + content workspace.
Mobile: compact top bar + bottom navigation where useful.

## Business Overview
Foundation-level only in Phase A:
organization status, verification status, profile completion and real quick actions. No fake analytics.

## Admin Foundation
Simple operational shell with real metrics only if actually available. No fake data.

## Product detail — future
Clearly answer what, who sells it, verification, authorized price, unit, MOQ, availability, lead time and procurement/buy action.

## Checkout — future
Cart → delivery choice → address if needed → review → payment → confirmation.

## Procurement — future
RFQ workspace, quote comparison, supplier rows, MOQ, quantity/unit, requested delivery date, negotiated price, PO/invoice references.

## Logistics — future
Clear delivery timeline and useful driver/ETA/destination/proof information without overwhelming technical map data.

## Responsive QA
Check 360, 390, 768, 1024 and 1440px. No horizontal overflow.
